# Контекст проекта

## Что это

`3dprint42.ru` — сайт Центра 3D-печати в Кемерово. Он одновременно решает четыре задачи:

1. представляет услуги и собирает органический поисковый трафик;
2. принимает заявки через формы и короткий квиз;
3. показывает каталог деталей с интерактивным просмотром STL и STEP/STP;
4. предоставляет защищённую админку и производственный кабинет команды.

## Основные услуги

- 3D-печать функциональных деталей;
- прототипирование и мелкосерийное производство;
- 3D-моделирование;
- реверс-инжиниринг;
- 3D-сканирование;
- печать фигурок и индивидуальных изделий.

## Публичные контакты

- город: Кемерово;
- адрес: ул. Сибирская, 36;
- телефон и ссылки на Telegram, VK, MAX управляются настройками сайта;
- основной домен: `https://3dprint42.ru`.

## Принципы продукта

- посетителю не требуется знать технологию или пластик — сначала выясняется задача;
- стоимость на публичной части не обещается как окончательная без проверки модели;
- основной конверсионный сценарий — квиз или форма заявки;
- старый публичный калькулятор удалён, его адрес перенаправляет на квиз;
- персональные данные заявки хранятся только в защищённой админке;
- Telegram получает только обезличенное уведомление о новой заявке.

## Источники истины

- страницы и тексты: `app/`;
- публичные маршруты: `site-routes.ts`;
- каталог по умолчанию: `app/model-catalog-data.ts`;
- production-каталог, заявки и CRM: каталог из `CATALOG_DATA_DIR`;
- переменные окружения без значений: `.env.example`.
