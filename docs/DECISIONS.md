# Журнал решений

## 2026-09 — Проектная память хранится в Git

Контекст распределён между коротким `AGENTS.md` и тематическими файлами `docs/`. Любой новый чат Codex на другом компьютере восстанавливает контекст из репозитория без объединения истории чатов.

## 2026-09 — Секреты и рабочие данные не синхронизируются через Git

В Git входят код, документация, публичные материалы и `.env.example`. Заявки, CRM, загруженные модели, сессии, пароли и токены остаются вне репозитория.

## 2026-09 — Уведомление о заявке обезличено

Полные данные заявки сохраняются в админке. Telegram сообщает только о появлении новой заявки и не получает имя, телефон, текст, файл или источник.

## 2026-09 — Публичный калькулятор отключён

Пользователь направляется в короткий квиз. Старый URL калькулятора сохранён как постоянный редирект на `/#quiz`.

## 2026-09 — STEP просматривается на сайте

Админка принимает STL, STEP и STP. STEP/STP преобразуется для просмотра средствами OCCT в браузере; скачивание исходных файлов посетителю не предлагается.

## 2026-09 — Файловое хранилище пока сохраняется

Для текущего объёма используется JSON и каталоги на одном сервере. Перед несколькими экземплярами приложения или существенным ростом требуется PostgreSQL и объектное хранилище.
